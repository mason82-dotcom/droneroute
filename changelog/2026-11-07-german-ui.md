## Summary

The interface is available in German.

## Changes

- Lightweight translation with English source strings as keys (`t()` in `src/lib/i18n.ts`,
  German texts in `src/lib/i18n.de.ts`); untranslated texts stay English.
- Language follows the browser, can be set in the settings (Deutsch/English) or with
  `?lang=de` / `?lang=en`.
- About 240 texts translated: sidebar, mission settings, waypoint and action editors, templates,
  map controls, routes, sharing, account dialogs, toasts and the new DJI check.
